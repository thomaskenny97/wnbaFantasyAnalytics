## Project Overview

wnbaFantasyAnalytics is a web application designed to help WNBA fantasy basketball players make better roster and lineup decisions.

The app analyzes player performance, recent trends, and fantasy-relevant statistics to surface:
- The best players to start each day
- High-upside available free agents
- Simple, explainable fantasy projections

This project prioritizes:
- Clarity over complexity
- Incremental feature development
- Human-readable analytics over black-box models
